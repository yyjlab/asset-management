# 配件库存

超级管理员进入“资产 → 配件”，按类型、品牌、公司和存放位置入库。鼠标、键盘、电源、转接头使用同一套库存。

## 日常使用

1. 首次点击“入库”，填写类型、品牌、公司、位置和数量。同一组合已有库存时使用“补货”。
2. 新增或编辑电脑，先选择公司、位置，再在“随附配件”中选择品牌方块和数量。保存成功才占用库存。
3. 电脑未领用时为“已配套”；电脑领出后为“使用中”。两者均不能再次分配。
4. 减少或移除库存配件，保存时需确认已实际拆下并退库。损坏配件退库后在库存页面记为“报废”。
5. 点击“明细”查看当前关联电脑、领用人和最近100条库存操作。更早记录在日志中查看。

归还电脑不自动拆下配件，仍保留配套关系。带库存配件的电脑不能直接删除，须先确认配件退库。报废数量不能当作可用库存。

## 旧数据与更新

旧资产、旧配件目录和独立鼠标资产均保留，不按名称自动合并、不自动扣库存；历史独立鼠标资产仍在“全部资产”中查询。新的配件选择只使用真实库存，旧目录不再供新分配。

首次使用前需人工盘点可用库存并入库。旧文字配件需要人工核对后重新选择新库存，不应把未盘点的在用数量直接当作库存入库。

新增 `accessory_stock` 表和 `asset_related_devices.stock_id` 可空列。项目现有 `ddl-auto: update` 会在新版后端首次启动时补充结构。升级前按现有备份流程备份数据库，前后端一同更新，库存功能不要与旧版后端混用。
