# 登记核对

超级管理员打开“资产 → 登记核对”，默认查看未登记人员。人员来自独立核对名单，不是系统登录账号。

首次使用：点击“名单管理”，从 Excel 复制“座位号、部门、姓名”三列粘贴，或一行一个姓名。核对预览后确认导入，每次最多1000人。“空置”自动忽略；按去除首尾空格后的姓名精确去重，同批或已有姓名跳过，不覆盖原部门、座位。真正同名的不同人员也会跳过，需要人工核对，不能把姓名当作可靠身份编号。

日常打开页面即可查看；页面可见时每30秒重新核对，也可以点击刷新。只有已领用且未报废的笔记本或台式电脑匹配领用人，才显示已登记；待审核的采集填报单独显示待审核。部门不一致，或仅匹配到报废、领用状态异常的电脑，显示待确认。显示器、鼠标不计入电脑登记。

未登记表示没有匹配的电脑领用记录，不代表没有实际电脑；拼写错误、别名、没有填写领用人、自定义电脑分类未使用现有电脑分类名称，都需要人工检查。查询依据全量后台记录，不依赖资产列表当前搜索或分页。核对过程不修改已有资产。

上线会按项目现有数据库结构更新机制新增 registration_roster 表；不自动写入座位图片里的人员、不修改历史资产。实际人员名单应由管理员在导入预览后确认，避免图片识别错字及将员工名单写入代码仓库。
