# 电脑采集

在“设置 → 电脑采集”选择 Windows 或 macOS，填写资产系统地址，下载采集包并完整解压到电脑本地或 U 盘。Windows 双击“一键采集.cmd”；macOS 在终端输入 bash 和空格，把“一键采集.command”拖入并回车，无需 sudo，不要关闭系统安全保护。填写实际使用人姓名（必填）和部门（选填），确认后提交。取消弹窗不发送。成功后可以关闭窗口或拔出 U 盘。

电脑须能访问资产系统；HTTP 需先在“装机平台接入”允许受信内网传输。HTTPS 使用 Windows 信任的证书，不跳过验证。无需安装 Python，不重启、不改名、不加域、不修改硬盘。

提交后在“资产入库”核对并批准，才生成资产编号。AD 自动送审和 Windows 采集都能填写可选领用人、部门及入域状态。填写领用人按已领用入库，留空按当前可用入库；入域状态仅记录资料。批准后当前浏览器的资产列表自动刷新。

采集包内含专用凭据，不要公开或上传代码仓库。凭据只能提交 Windows 采集，不能查询资产或批准入库。有效期最长 90 天；在下载页撤销后，所有副本都不能继续提交，已登记资料不受影响。

同一硬件 UUID 再次采集返回原记录，不重复创建或覆盖硬件快照；待审核记录可通过再次运行修正填报姓名、部门，已批准或未批准的记录不通过脚本修改。填报信息在资产入库列表和核对窗口显示，仅作审核参考，不自动领用。未批准记录在资产系统修正并重新送审。不使用 SN 关联，也不会自动合并已有 AD 或手工登记资产。硬件 UUID 无效时停止提交。采集包 records 目录保存首次采集快照及填写信息，网络失败可再次运行重试，请妥善保管，不要公开传播。

电脑与当前系统识别到的显示器一起送审，记录品牌、SN、近似尺寸和内置/外接类型。没有检测到屏幕不代表是笔记本；电脑类型独立识别。尺寸不根据像素分辨率推测。鼠标和键盘只记录品牌，未检测到或品牌未识别显示“无”，不单独创建资产。

审核时勾选尚未登记的外接显示器，补充缺失品牌并确认未重复登记，再批准。电脑与所选显示器分别生成编号，沿用同一领用人、部门；整单失败则回滚，重复批准不重复创建。内置屏和连接类型不明的屏幕不能单独入库，缺少唯一启用的“显示器”分类时明确报错，不自动新建分类。显示器未采集型号，资产型号标为“型号未采集”。SN 只是描述，不按 SN 自动合并。

再次运行可以更新待审核单的外设信息；已批准或未批准的单不通过脚本覆盖，已有电脑不会重复建档。已入库电脑新增显示器的补登记不在当前自动流程内，请在资产系统核对后处理。

基础显示驱动不当作真实显卡，USB 硬盘不计入内置硬盘。旧采集包需要重新下载才包含新字段。macOS 的解析和收包已用测试资料验证，但当前开发机不是 Mac，osascript、硬件和外设兼容性尚需实机测试；不同 macOS、扩展坞和显示器可能读不到 SN 或尺寸。
