# Windows 采集

在“设置 → Windows 采集”填写资产系统地址，下载采集包并完整解压到 U 盘。每台已启动 Windows 的电脑双击“一键采集.cmd”，看到提交成功后即可拔出 U 盘，继续下一台。Windows 不允许普通 U 盘插入后自动执行，因此每台需要双击一次。

电脑须能访问资产系统；HTTP 需先在“装机平台接入”允许受信内网传输。HTTPS 使用 Windows 信任的证书，不跳过验证。无需安装 Python，不重启、不改名、不加域、不修改硬盘。

提交后在“资产入库”核对并批准，才生成资产编号。AD 自动送审和 Windows 采集都能填写可选领用人、部门及入域状态。填写领用人按已领用入库，留空按当前可用入库；入域状态仅记录资料。批准后当前浏览器的资产列表自动刷新。

采集包内含专用凭据，不要公开或上传代码仓库。凭据只能提交 Windows 采集，不能查询资产或批准入库。有效期最长 90 天；在下载页撤销后，所有副本都不能继续提交，已登记资料不受影响。

同一硬件 UUID 再次采集返回原记录，不重复创建或覆盖；不使用 SN 关联，也不会自动合并已有 AD 或手工登记资产。未批准记录在资产系统修正并重新送审。硬件 UUID 无效时停止提交。U 盘 records 目录保存首次采集快照，网络失败可再次运行重试，不要随意修改快照。

未采集到的信息留空，由审核人核对；基础显示驱动不当作真实显卡，USB 硬盘不计入内置硬盘。尚需在实际 Windows 10/11 电脑验证硬件兼容性。
